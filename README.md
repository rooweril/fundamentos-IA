# Fundamentos de Inteligencia Artificial
# FABRIZZIO NARVAEZ FRANCO
Repositorio destinado al desarrollo y entrega de las actividades prácticas de la materia **Fundamentos de Inteligencia Artificial**.

## 📂 Estructura del repositorio

Los laboratorios deberán organizarse dentro de la carpeta `Laboratorios`, utilizando un archivo de Jupyter Notebook (`.ipynb`) para cada práctica.

```text
Fundamentos-IA/
│
├── Laboratorios/
│   ├── Lab01.ipynb
│   ├── Lab02.ipynb
│   ├── Lab03.ipynb
│   ├── Lab04.ipynb
│   └── ...
│
└── README.md
```

## 🧪 Laboratorios

Cada laboratorio deberá contener el desarrollo de la actividad correspondiente, incluyendo, cuando aplique:

* Objetivo de la práctica.
* Descripción del problema.
* Código fuente.
* Explicación de los procedimientos realizados.
* Resultados obtenidos.
* Conclusiones.

### Entrega semanal

Los laboratorios deberán subirse **semanalmente** al repositorio de GitHub.

Cada semana se deberá agregar el archivo correspondiente dentro de la carpeta `Laboratorios`, respetando la siguiente nomenclatura:

```text
Lab01.ipynb
Lab02.ipynb
Lab03.ipynb
...
```

Por ejemplo, para la primera semana:

```text
Laboratorios/
└── Lab01.ipynb
```

Para la segunda semana:

```text
Laboratorios/
├── Lab01.ipynb
└── Lab02.ipynb
```

## 📌 Recomendaciones

* Mantener actualizado el repositorio durante el semestre.
* No eliminar los laboratorios previamente entregados.
* Verificar que el archivo `.ipynb` se pueda abrir correctamente en GitHub.
* Ejecutar las celdas antes de realizar la entrega y comprobar que los resultados se encuentren visibles.
* Utilizar nombres de archivos claros y respetar la nomenclatura establecida.
* Realizar un `commit` y `push` después de cada entrega semanal.

## 🔄 Flujo de entrega

El proceso recomendado para cada laboratorio es:

1. Descargar o actualizar el repositorio.
2. Crear o modificar el notebook correspondiente.
3. Ejecutar y verificar el laboratorio.
4. Guardar los cambios.
5. Realizar el `commit`.
6. Subir los cambios a GitHub mediante `push`.

Ejemplo:

```bash
git add Laboratorios/Lab01.ipynb
git commit -m "Entrega Lab01"
git push
```
